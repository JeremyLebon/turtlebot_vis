Rijden: knoppen in beeld (ook schuin: vooruit + draaien), of WASD en pijltjes (klik eerst in de 3D-weergave), numeriek klavier 7913 = schuin, spatie stopt. Mecanum: Shift + ◀ ▶ of de knop zijwaarts. Lokaal rijden heeft voorrang op /cmd_vel.

    Sensoren (zoals de echte TurtleBot3)

    –

    Publiceert /battery_state en /sensor_state (encoders, knoppen SW1/SW2 ingedrukt houden) en beantwoordt de service /sound met een piep. Onder 11,0 V vallen de motoren uit, zoals op de echte robot.

    Gamepad (/joy)

    Geen gamepad aangesloten: gebruik de knoppen (ingedrukt houden).

    Zoals de Logitech F710 op de robot: sensor_msgs/Joy, A = buttons[0], B = 1, X = 2, Y = 3, LB = 4, RB = 5; linker stick = axes[1] (op = +), rechter stick = axes[3] (links = +). Met LB ingedrukt rijdt de robot met de sticks, zoals op de echte robot. Een gamepad aan je pc werkt ook (druk eerst een knop in).

    /sensors/temperature · /sensors/humidity · /sensors/pressure · /sensors/illuminance · /sensors/gas/co2 · /sensors/gas/tvoc · /sensors/gas/co · /sensors/sound: hangen af van de plaats van de robot, zelfde topics als de gesimuleerde sensoren op de echte robot (sessie 4). De oude /sim/...-topics lopen nog mee.

    Rij rond: elke meting (1× per seconde) wordt een bolletje in de kleur van de waarde, blauw = laag, rood = hoog.

    Kaartlagen (Nav2 en SLAM)

    Costmaps en paden staan standaard uit: rosbridge moet ze voor de simulator omzetten naar JSON, en de Fenix-pagina toont ze al. Zet ze aan als je ze hier wilt zien.

    Kies onderaan Startpositie of Doel, klik op de vloer en sleep voor de richting. Dat publiceert /initialpose en /goal_pose in frame map. Kaarten worden op hun plaats getekend via map → odom uit /tf.

    Nog geen kaart ontvangen.

    Student

    Naam en code verschijnen op de vloer, in het camerabeeld, in de HUD en op /student_id.

    Test

      Lever het rapport (.json) en de opname samen in. De opname hoort bij het rapport via haar SHA-256 in het rapport.

      Verbinding

      Type wordt herkend zodra je script op /cmd_vel publiceert.

      Zet uit als je robot_state_publisher draait. Die maakt dan zelf de frames uit de URDF en /joint_states.

      Robot

      Ingebouwde Burger geladen (primitieve vormen, met camera en 3D-lidar).

      Robotconfiguratie

      Sensoren zitten op het gekozen frame: de lidar scant in het xy-vlak van dat frame, de camera kijkt langs +x. Automatisch herkend op naam.

      Joints

      Ook via ROS: sensor_msgs/JointState op /joint_commands (naam + positie).

      Sensoren en odometrie

      /points: x y z intensity (float32), ring (uint16), time (float32, s na het begin van de scan), zoals de Velodyne-driver. De scan loopt over de omwenteling (bewegingsvervorming, voor deskew en LIO). Zware types vragen veel van de laptop.

      Extra sensoren (zoals in Gazebo)

      Vaste frames aan de robot in /tf_static: gps_link, sonar_front_link, sonar_left_link, sonar_right_link, radar_link; de dieptecamera gebruikt het frame van de robotcamera. De wereld-x wijst naar het oosten, y naar het noorden; de GPS rekent vanaf geo in de wereld (lat, lon, alt). Waarden ook in de HUD.

      Eigen wereld

      Eigen wereld: sla een ingebouwde wereld op als vertrekpunt en pas de JSON aan. Elementen (maten in m, hoeken in graden): wall x0 y0 x1 y1 [t h], box x y [z] sx sy sz [yaw pitch], cyl x y r h, rack x y [bays depth h yaw], conveyor x y l [w h yaw], pallet x y [load], table x y [l w h yaw], chair x y [yaw], movable x y [sx sy sz mass], mark x y sx sy [yaw]; elk met optioneel color. Buiten: tree x y [h crown r], orchard x y [rows n row gap yaw h crown jitter missing], fence x0 y0 x1 y1 [h gap opacity], sphere x y [z] r, crops x y [plant rows l row w h gap yaw] (plant: mais, kool, aardappel), aruco x y [z] yaw id [size], uwb x y [z id], line pts [[x, y], …] [w closed]; elk element optioneel temp (°C, voor de thermische camera). Hoogteverschillen: terrain {res, base, tilt [ax, ay], hills [{x, y, h, s}], wave {amp, len}}; alles staat dan op de grond. Verder floor [sx, sy], spawn [x, y, θ], ground en sky (kleur) en geo {lat, lon, alt} voor de GPS.

      Starten in je container 
      # container met poort 9090 open (ports: "9090:9090")
sudo apt install ros-jazzy-rosbridge-suite \
  ros-jazzy-slam-toolbox ros-jazzy-navigation2 \
  ros-jazzy-nav2-bringup ros-jazzy-turtlebot3*
export TURTLEBOT3_MODEL=burger
ros2 launch rosbridge_server rosbridge_websocket_launch.xml

# SLAM (kaart maken)
ros2 launch slam_toolbox online_async_launch.py use_sim_time:=true

# Nav2 bovenop SLAM, met de Burger-parameters
PARAMS=$(find $(ros2 pkg prefix turtlebot3_navigation2) -name burger.yaml | head -1)
ros2 launch nav2_bringup navigation_launch.py use_sim_time:=true params_file:=$PARAMS

# of Nav2 met een opgeslagen kaart (AMCL)
ros2 run nav2_map_server map_saver_cli -f ~/kaart --ros-args -p use_sim_time:=true
ros2 launch turtlebot3_navigation2 navigation2.launch.py use_sim_time:=true map:=$HOME/kaart.yaml

# rijden (Jazzy: stamped), camera bekijken
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -p stamped:=true
ros2 run rqt_image_view rqt_image_view /camera/image_raw/compressed
